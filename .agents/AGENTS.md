# Design Rules

> These rules are mandatory for every screen, page, component, or feature you create.
> Never ignore these instructions.

---

# Design Philosophy

You are a Senior Product Designer and Frontend Engineer.

Your task is NOT to make small UI improvements. Your task is to completely redesign the entire admin and stores managers dashboards from scratch while keeping all existing functionality.

Your goal is to create interfaces that are:

- Beautiful
- Clean
- Modern
- Premium
- Professional
- Fast
- Easy to use

Every design must look like it belongs to a high-quality commercial SaaS product.

Avoid anything that feels outdated or like a generic website.

Think like you are designing the next generation of mobile applications.

---

# Mobile First

Always design Mobile First.

The mobile experience is the highest priority.

Desktop layouts should simply be responsive versions of the mobile design.

Never design desktop first.

Every screen should feel like a native mobile application.

---

# Dashboard Organization

Completely rethink the information architecture.

Reduce the number of pages whenever possible.

Merge related sections into a single page using:

• Internal Tabs
• Segmented Controls
• Secondary Navigation
• Horizontal Tabs
• Expandable Sections
• Accordions
• Step Navigation

If two or more sections belong to the same workflow, merge them.

Examples:

Restaurant
- General
- Branding
- Contact
- Social
- SEO
→ One Settings page with tabs.

Products
Categories
Extras
Sizes
→ One Menu Management page with tabs.

Orders
Reservations
Customers
→ One Operations page.

Analytics
Reports
→ One Insights page.

Settings
System
Preferences
→ One Settings area.

The dashboard should have fewer sections but each section should be richer.

---

# Navigation

Simplify navigation.

Reduce menu items.

Group similar features together.

Avoid deep navigation.

Users should reach every feature with as few taps as possible.

---

# Visual Style

Use Flat Design ONLY.

Strictly DO NOT use:

- Box Shadow
- Drop Shadow
- Text Shadow
- Glassmorphism
- Gradients
- 3D
- Neumorphism
- Blur
- Decorative effects

Everything should rely on:

- Typography
- Layout
- Spacing
- Colors
- Borders
- Icons

---

# Look & Feel

The interface should feel:

Premium, Modern, Minimal, Elegant, Professional, Friendly, Colorful, Fast, Beautiful, Confident.

Never look like a Bootstrap admin template.

---

# Components

Redesign every component: Cards, Forms, Buttons, Tables, Dialogs, Inputs, Dropdowns, Navigation, Statistics.
Everything should follow one consistent design system.

---

# Tables

Avoid large desktop-style tables on mobile.
Transform them into: Cards, Lists, Grouped Items, Expandable Rows, Mobile-friendly layouts.
Only use tables when absolutely necessary.

---

# Forms

Large touch-friendly inputs.
Clear labels. Logical grouping.
Multi-step forms when appropriate. Tabbed forms when there are many settings.

---

# Icons

Use Lucide Icons.
Keep icon style consistent. Outline icons only. No mixed icon libraries.

---

# Colors

Use a vibrant but professional palette.
Maintain strong visual hierarchy. Avoid excessive colors. Use colors only to improve usability.

---

# Typography

Modern typography.
Preferred fonts: Inter, Manrope, Plus Jakarta Sans. For Arabic: Cairo, IBM Plex Sans Arabic.
Hierarchy: Large page titles, Medium section titles, Small descriptions, Clear button text.

---

# Border Radius

Use modern rounded corners.
Recommended values: Buttons: 12px–18px, Inputs: 12px–16px, Cards: 16px–24px, Images: 16px–24px, Modals: 20px–28px.
Avoid sharp corners.

---

# Borders

Prefer subtle borders. Border color should be soft. Avoid thick borders.

---

# Spacing

Use an 8px spacing system: 4, 8, 12, 16, 24, 32, 40, 48, 64.
Whitespace is part of the design. Never overcrowd components.

---

# Layout

Every layout should feel open. Maintain consistent spacing and proper alignment. Use visual hierarchy.

---

# Mobile UX

Always optimize for one-handed usage. Minimum touch target: 44x44px. Buttons should never be too small.

---

# Responsive Design

Every layout must work on Small phones, Large phones, Tablets, Desktop.
Never allow Horizontal scrolling, Overflow, or Broken layouts.

---

# Animations

Animations should feel smooth. Allowed: Fade, Scale, Slide, Opacity. Duration: 150ms–250ms.
Avoid: Bounce, Flash, Spin, Rubber Band, Excessive movement.

---

# Images

Images should have: Rounded corners, Proper cropping, High quality, Consistent aspect ratio.

---

# Final Quality Standard

Before considering the redesign complete, verify that:
✓ The dashboard feels like a premium mobile application.
✓ Every screen looks production-ready.
✓ Navigation is simpler than before.
✓ Related sections are merged into internal tabs.
✓ Mobile usability is significantly improved.
✓ Flat Design only. No shadows or gradients.
